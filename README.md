# 🔎 Port Scanner

Um simples **scanner de portas TCP desenvolvido em Python**, utilizando a biblioteca `socket`.

O projeto foi criado com o objetivo de estudar conceitos fundamentais de **redes de computadores, sockets, portas TCP e reconhecimento de serviços**, servindo também como uma introdução prática à área de **cibersegurança**.

---

## 🚀 Funcionalidades

- Verifica portas TCP de um determinado host.
- Identifica quais portas estão abertas.
- Permite informar o host pelo terminal.
- Permite definir portas específicas para escaneamento.
- Utiliza timeout para evitar que o programa fique preso em conexões que não respondem.

---

## 🛠️ Tecnologias utilizadas

- **Python 3**
- `socket`
- `sys`
